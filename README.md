# UMBRA

Authorized black-box recon and model red-team console.

## Features

- **1–128 agents** in parallel waves (configurable wave size 1–32)
- **OpenRouter free pack**: inclusionai/ling-3.0-flash-vl:free, nvidia/nemotron-3.5-lightning:free, z-ai/glm-5.2:free, nvidia/nemotron-3-ultra-550b-a55b:free, nex-agi/nex-n2.5-pro:free, nex-agi/nex-n2.5-mini:free
- **Group space**, reportable findings, live agent thinking, model lab, run summary

## Setup

```bash
npm install && npm run dev
```
